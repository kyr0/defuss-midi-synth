System Requirements:

- MIDI File player capable of reading Type 1 Standard MIDI file format
- General MIDI sound device (Wave Table or SC-55 compatible recommeded)



This Standard MIDI File was recorded directly from Dynamix's "Red Baron"
simulation game.  It has been converted from the MT-32 version for playback
on General MIDI sound cards.  A Wave Table or Sound Canvas compatible device
is highly recommended.
