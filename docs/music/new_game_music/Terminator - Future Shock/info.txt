*** Additional info ***
The FM* and GM* tracks have been found at the original floppy version and were converted from XMI format using
XMI2MID tool.

The CD* tracks were the enhanced tunes found at CD version of the game released later. These were converted 
from HMI format using Winamp, except track CDINTRO.MID, which was recorded from the sound setup tool (WinAmp
crashed on original HMI file :) ).
